Alina Market Lab

AI trade desk · ข้อมูลจริงจาก repo · อัปเดต
อ่านก่อน: ระบบนี้ยังไม่มี edge ที่ผ่านการทดสอบ ทุกกลยุทธ์ที่ทดสอบมา (168 เทสต์ + 6 การทดลอง pre-register) ล้มหรือไม่ผ่าน hold-out หน้านี้จึงเป็น กระดานข้อมูล + ตัวคุมความเสี่ยง ไม่ใช่สัญญาณซื้อขาย ห้ามใช้เงินจริง

1. สถานะตลาดตอนนี้ (คำนวณสดจากข้อมูลในเครื่อง)

risk weight = target vol 10% ÷ vol ของสินทรัพย์ (cap 3×) — เป็นขนาดความเสี่ยง ไม่ใช่คำแนะนำทิศทาง

2. ตารางสัญญาณ 24 สินทรัพย์

3. ของฟรีจากเว็บ (332 แหล่ง) — ทดสอบแล้วได้อะไร

4. Martingale / Grid — สิ่งที่แจกฟรีเยอะที่สุด และมันทำอะไรกับบัญชี

ทุกสินทรัพย์ที่ทดสอบ = บัญชีถูกกวาด (wiped) ไม่ใช่เรื่องบังเอิญ — lot doubling ทำให้การขาดทุนครั้งเดียวมีขนาดเท่าทุกกำไรที่สะสมมา

5. ประวัติการทดลอง (ทั้งหมดถูกบันทึกและ push ขึ้น GitHub)

6. Risk Governor — ค่าที่ EA บังคับใช้

7. วิธีรัน

  • เปิด MT5 → File ▸ Open Data Folder → MQL5/Experts/ → วาง AlinaRiskGovernor.mq5
  • F4 เปิด MetaEditor → กด F7 compile → กลับ MT5 กด Refresh ที่ Navigator
  • ลาก EA ลงกราฟ บัญชี DEMO เท่านั้น → ตั้ง InpMode = PAPER เพื่อทดสอบโดยไม่ส่งคำสั่งจริง
  • เปลี่ยนเป็น LIVE_SAFE ได้เมื่อผ่าน demo ต่อเนื่อง ≥ 3 เดือน และมี log ครบ
EA นี้ไม่ใส่กลยุทธ์ที่ "ชนะ" เพราะยังไม่มี — มันใส่ วินัยความเสี่ยง ที่ทดสอบแล้วว่าจำเป็น
