# วิธีติดตั้ง EA (AlinaRiskGovernor) — อ่านก่อนใช้

## สถานะจริงของงานนี้ (อ่านให้จบ)

- โครงการทดสอบมา **6 การทดลอง pre-register + 168 screen tests + 144 free-EA family tests** → **ยังไม่มี edge ที่ผ่าน**
- EA นี้จึงไม่ใช่ "บอททำเงิน" แต่เป็น **ตัวคุมความเสี่ยง + โครงสำหรับเก็บ log** ที่บล็อกวิธีที่พิสูจน์แล้วว่าเจ๊ง
- **ยังไม่ได้ compile** — ผมเขียนและ lint ด้วยสคริปต์ (`scripts/lint_mq5.py`) แล้ว แต่ sandbox นี้ไม่มี MetaEditor
  ครั้งแรกที่คุณกด F7 คือการทดสอบจริงครั้งแรก

## ติดตั้ง (5 นาที)

1. เปิด MT5 → `File ▸ Open Data Folder`
2. เข้า `MQL5/Experts/` → วางไฟล์ `AlinaRiskGovernor.mq5`
3. กด `F4` เปิด MetaEditor → เปิดไฟล์ → กด **F7** (Compile)
   - ถ้าขึ้น error ส่งบรรทัดนั้นมา ผมแก้ให้
4. กลับไป MT5 → คลิกขวาที่ `Navigator ▸ Expert Advisors` → `Refresh`
5. ลาก EA ลงกราฟ **บัญชี DEMO** → หน้าตั้งค่า → ตั้ง `InpMode = MODE_PAPER`

## โหมดการทำงาน

| โหมด | ทำอะไร |
|---|---|
| `MODE_PAPER` (ค่าเริ่มต้น) | คำนวณทุกอย่าง เขียน log แต่ **ไม่ส่งคำสั่ง** — ใช้เก็บหลักฐาน |
| `MODE_LIVE_SAFE` | ส่งคำสั่งจริง **แต่ยังอยู่ใต้ risk governor** — ห้ามใช้กับเงินจริงจนกว่าจะมี log demo ≥ 3 เดือน |

## ตัวคุมความเสี่ยงที่บังคับใช้ (แก้ไม่ได้ผ่าน input ที่ไม่ควรแก้)

| กฎ | ค่าเริ่มต้น | บล็อกอะไร |
|---|---:|---|
| ขาดทุนสูงสุดต่อวัน | 3% | หยุดเทรดทั้งวัน |
| Drawdown จากจุดสูงสุด | 20% | **ล็อกถาวร** ปิดทุกออเดอร์ ต้องรีเซ็ตมือ |
| ความเสี่ยงต่อไอเดีย | 2% | คุมขนาดไม้ด้วย stop 1.5×ATR |
| spread สูงสุด | 30 points | ไม่เข้าเมื่อต้นทุนแพง — ต้นทุนคือสิ่งที่ฆ่า edge ที่ทดสอบมาทั้งหมด |
| จำนวนโพซิชัน | 1 | ไม่ถัว ไม่เพิ่มไม้ |
| martingale / doubling | **บล็อก** | ไม่มีโค้ดแบบนี้เลย และมี lint test จับ |

## สัญญาณ (ปิดไว้โดยค่าเริ่มต้น)

`InpSignal = SIG_NONE` (แนะนำ) · `SIG_DONCHIAN` (55 วัน) · `SIG_ZFADE` (z 20 วัน, ±2σ)

ทั้งสองแบบ **ถูกทดสอบแล้วและไม่ผ่าน** — ใส่ไว้เพื่อเก็บ log demo เท่านั้น ไม่ใช่คำแนะนำให้เปิด

## สิ่งที่จะเห็นใน log

`MQL5/Files/alina_governor.log` — บรรทัดละเหตุการณ์: เริ่มระบบ, ทุกครั้งที่ governor บล็อก,
ขนาดไม้ที่คำนวณได้, halt พร้อมเหตุผล ส่งไฟล์นี้มาให้ผมวิเคราะห์ได้ทุกเมื่อ

## กติกาที่ผมจะยึด

- ไม่มีคำแนะนำให้ใช้เงินจริงบนระบบที่ยังไม่มี edge
- ไม่ปรับพารามิเตอร์ให้ดูดีขึ้นหลังเห็นผล (นั่นคือ overfit)
- ถ้าคุณสั่งให้เปิด live ผมจะบอกความจริงซ้ำหนึ่งครั้ง แล้วทำตามที่คุณสั่ง — เงินเป็นของคุณ
