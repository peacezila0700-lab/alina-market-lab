# ALINA DATAPACK v2.1 — read this first (≈900 tokens, saves you thousands)

## What this is
A self-contained research base built by an agent over ~12 sessions, for an AI trading system to
consume **without re-searching the internet**. It contains market data, positioning data,
volatility data, measured trading costs, calendars, an attention proxy, a catalogue of 332 free
EAs, **34 datasets** including a 68-ETF cross-section, news headlines with entity tags, per-instrument
support/resistance levels, and a **ready-made daily brief** (`briefs/latest.md`) — plus **every
experiment run here with its verdict**.

**If you only read one file after this one, read `briefs/latest.md`** — it is the entire current state
of the market compressed to ~1.5k tokens, regenerated by `scripts/daily_brief.py`. `OPERATING_MANUAL.md`
explains the daily loop and what NOT to rebuild.

## The one thing you must know
**No validated edge was found.** 168 screen tests, 144 free-EA family tests, 14 pre-registered
experiments -> all rejected or failed hold-out. Three failed this session on the widest panel yet:
event-conditional direction (EXP-0010), Treasury auction demand (EXP-0011), cross-sectional
momentum/reversal on 68 ETFs (EXP-0012), market-state sizing overlays (EXP-0013) and the dealer-gamma
overlay vs plain volatility targeting (EXP-0014). The durable lesson from the last two: state variables
move *volatility*, not expected return — use them for size, never for direction. One apparent Sharpe 1.72 was traced to a
look-ahead bug in this repo's own code. Treat every number here as *evidence*, not as a strategy.

## How to use this pack efficiently
1. Read `catalog.json` — each dataset has schema, rows, coverage, sha256, a 2-row preview,
   caveats, a `leak_rule`, and a grade. Decide from the catalog; only then open the CSV.
2. Read `results/experiments.jsonl` — 14 experiments, machine-readable. **Check here before
   testing any idea**: if it is in the list, it is already dead.
3. Read `knowledge/PITFALLS.md` before writing any backtest code. It will save you from the
   three bugs that produced every fake edge in this repo.
4. `cards/<dataset>.md` — 150–250 words per dataset if you need prose instead of JSON.

## Grades (trust level)
- **A** = official primary source (ECB, CFTC, CBOE, Federal Reserve). Use freely.
- **B** = computed here with a documented method (spreads, screens, verdicts). Use with the stated caveat.
- **C** = third-party, shape only. **Never** use for absolute levels or returns (Yahoo FX).

## Hard rules (violating these recreates known failures)
1. **Lag every position one bar.** `pnl[t] = pos[t-1] * ret[t]`. This bug alone invented a
   30% CAGR that did not exist.
2. **Charge costs on every position change**, using `data/spreads_measured_dukascopy` for FX.
   A wrong cost assumption flipped a verdict in this project: EURUSD is 0.3 pip on ECN,
   EURSEK is 48 pips.
3. **Use `available_from`, not `report_date`,** for COT (Tuesday as-of, Friday public).
4. **Never use Yahoo FX returns** (correlation with official fixes: 0.38–0.52). Use
   `fx_official_ecb_daily`.
5. **Report a null.** Every result needs a turnover-matched random control; otherwise you are
   measuring luck. Random selection loses ~0.3 Sharpe after costs — that is the sanity check.
6. **Never martingale.** 5 of 5 instruments in the grid/doubling test were wiped.

## New in v2.1 (what to actually use)
- `briefs/` — the daily state file. **Start every analysis here.**
- `levels_support_resistance` — pivots, prior-day/week levels, value areas, ATR for 28 instruments.
- `news_headlines` + `news_pressure` — 294 headlines/15 feeds with entity tags and per-day counts;
  useful for *context and timing*, never for direction (no edge in the sentiment counts so far).
- `broad_cross_section` — 68 ETFs, 38 MB, 11 sectors / 16 countries / credit / commodities / vol
  wrappers / crypto proxies. The only panel wide enough for honest cross-sectional work.
- `research/artifacts/cross_section.json` — read this before running any factor test; it contains
  the turnover-matched null that killed three factors that had looked alive.
